# Tripti Birthday Website 💖

A simple static birthday website made for Tripti.

## Files
- `index.html` — complete website
- `images/` — four birthday photos

## Put it online free with GitHub Pages
1. Create/login to a GitHub account.
2. Create a **Public** repository.
3. Upload `index.html` and the entire `images` folder.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose `main` and `/ (root)`, then Save.
7. GitHub will give you a website URL such as:
   `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`

If you name the repository `YOUR-USERNAME.github.io`, the shorter URL is:
`https://YOUR-USERNAME.github.io/`
